태스크플로우 생성

"새 태스크플로우" 버튼을 클릭하여 태스크플로우를 생성합니다.

태스크플로우 생성 절차

  1. 1

    새 태스크플로우 버튼 클릭

    목록 상단의 "새 태스크플로우" 버튼을 클릭합니다.

  2. 2

    이름 입력

    태스크플로우 이름을 입력합니다.

  3. 3

    캔버스 에디터에서 작업 설계

    캔버스 에디터에서 태스크 노드를 배치하고 연결합니다.

  4. 4

    저장

    임시 저장 또는 최종 저장을 선택합니다.

태스크플로우 생성 입력 규칙

항목 규칙 비고
이름 필수 입력 중복 불가
버전 자동 생성 저장 시 자동 증가

검색 및 필터

태스크플로우를 효율적으로 찾기 위한 검색 및 필터 기능을 제공합니다.

검색 및 필터 기능

기능 설명 사용 방법
이름 검색 태스크플로우 이름으로 검색합니다. 검색창에 이름 입력
상태 필터 활성/비활성 상태로 필터링합니다. 상태 드롭다운에서 선택
정렬 최신순, 오래된순, 이름순으로 정렬합니다. 정렬 드롭다운에서 선택

일괄 작업

여러 태스크플로우를 선택하여 일괄 복사하거나 삭제할 수 있습니다.

일괄 복사 절차

  1. 1

    태스크플로우 선택

    복사할 태스크플로우의 체크박스를 선택합니다.

  2. 2

    일괄 복사 클릭

    상단의 "일괄 복사" 버튼을 클릭합니다.

  3. 3

    복사 완료

    선택한 태스크플로우가 복사되어 목록에 추가됩니다.
