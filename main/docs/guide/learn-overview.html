러닝 개요

러닝 메뉴는 로봇의 학습 데이터 준비, 학습 실행, 학습 상태 모니터링, 학습 결과 검토를 관리하는 기능입니다. 로봇이 새로운 환경과 작업을 학습할 수 있도록 지원합니다.

학습 유형

러닝 메뉴에서 제공하는 학습 유형을 소개합니다.

보고 배우기

로봇이 사람의 동작을 관찰하고 학습합니다. 카메라를 통해 사람의 행동을 인식하고 모방합니다.

원격 조작 학습

원격으로 로봇을 조작하면서 학습 데이터를 수집합니다. 텔레오퍼레이션을 통해 실제 환경에서 학습합니다.

시뮬레이션 학습

가상 환경에서 로봇을 학습시킵니다. 시뮬레이션을 통해 다양한 시나리오를 반복 학습합니다.

TMS 에피소드 학습

TMS 태스크플로우 실행 데이터를 기반으로 학습합니다. 실제 태스크 실행 경험을 활용합니다.

데이터 준비

학습에 필요한 데이터를 준비하고 업로드합니다.

데이터 준비 절차

  1. 1

    데이터 준비 페이지 이동

    러닝 메뉴에서 "데이터 준비" 페이지로 이동합니다.

  2. 2

    데이터 업로드

    학습에 필요한 데이터 파일을 업로드합니다.

  3. 3

    데이터 검증

    업로드된 데이터의 품질을 검증합니다.

  4. 4

    학습 준비 완료

    데이터 준비가 완료되면 학습을 시작할 수 있습니다.

데이터 업로드 입력 규칙

항목 규칙 비고
데이터 파일 필수 (지원 형식) 이미지, 비디오, 로그 파일
데이터 이름 필수 입력 중복 불가
설명 선택 입력 데이터에 대한 설명

학습 상태 모니터링

학습 진행 상태를 실시간으로 모니터링합니다.

학습 상태 유형

상태 표시 색상 설명
학습 중 파랑 학습이 진행 중인 상태
검토 대기 보라 학습이 완료되어 검토가 필요한 상태
완료 초록 학습이 완료되고 승인된 상태
실패 빨강 학습 중 오류가 발생한 상태

학습 결과 검토 및 승인

완료된 학습 결과를 검토하고 승인합니다.

검토 및 승인 절차

  1. 1

    검토 대기 목록 확인

    검토 대기 상태의 학습 결과를 확인합니다.

  2. 2

    학습 결과 검토

    학습 결과 데이터와 성능 지표를 검토합니다.

  3. 3

    승인 또는 반려

    검토 결과에 따라 승인하거나 반려합니다.

문제 해결

문제 원인 해결 방법
학습 시작 실패 데이터 준비가 완료되지 않음 데이터 준비 상태를 확인
학습 실패 데이터 품질 문제 또는 시스템 오류 데이터를 재검토하고 재학습
데이터 업로드 실패 지원하지 않는 형식 또는 용량 초과 지원 형식 및 용량 확인
