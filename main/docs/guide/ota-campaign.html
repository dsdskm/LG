OTA 캠페인 개요

OTA(Over-The-Air) 캠페인은 로봇의 소프트웨어, 펌웨어, 설정을 원격으로 업데이트하는 기능입니다. 아티팩트 업로드, 캠페인 생성, 정책 설정, 대상 그룹 지정을 통해 로봇을 효율적으로 업데이트합니다.

캠페인 생성

"캠페인 생성" 버튼을 클릭하여 새 OTA 캠페인을 생성합니다.

캠페인 생성 절차

  1. 1

    아티팩트 업로드

    업데이트할 소프트웨어/펌웨어 아티팩트를 업로드합니다.

  2. 2

    캠페인 정보 입력

    캠페인 이름, 아티팩트, 대상 그룹, 정책을 설정합니다.

  3. 3

    캠페인 실행

    캠페인을 즉시 실행하거나 예약합니다.

캠페인 생성 입력 규칙

항목 규칙 비고
캠페인 이름 필수 입력 중복 불가
아티팩트 필수 선택 업로드된 아티팩트 중 선택
대상 그룹 필수 선택 업데이트할 로봇 그룹
정책 필수 선택 업데이트 정책 (즉시/예약 등)

아티팩트 관리

업데이트에 사용할 소프트웨어/펌웨어 파일을 관리합니다.

아티팩트 업로드 절차

  1. 1

    아티팩트 탭 선택

    OTA 메뉴에서 "아티팩트" 탭을 선택합니다.

  2. 2

    파일 업로드

    업데이트 파일을 업로드합니다.

  3. 3

    아티팩트 정보 입력

    아티팩트 이름, 버전, 설명을 입력합니다.

아티팩트 업로드 입력 규칙

항목 규칙 비고
파일 필수 (지원 형식) FW, SW 패키지 파일
아티팩트 이름 필수 입력 중복 불가
버전 필수 입력 버전 형식 (예: 1.0.0)

정책 관리

업데이트 실행 방식을 정의하는 정책을 관리합니다.

정책 유형

정책 유형 설명 사용 시나리오
즉시 실행 캠페인 생성 즉시 업데이트를 실행합니다. 긴급 보안 패치
예약 실행 지정된 시간에 업데이트를 실행합니다. 업무 시간 외 업데이트
단계적 배포 일정 비율씩 단계적으로 업데이트합니다. 대규모 업데이트

대상 그룹 관리

업데이트를 적용할 로봇 그룹을 정의합니다.

대상 그룹 생성 절차

  1. 1

    대상 그룹 탭 선택

    OTA 메뉴에서 "대상 그룹" 탭을 선택합니다.

  2. 2

    그룹 생성

    그룹 이름과 설명을 입력하고 생성합니다.

  3. 3

    로봇 선택

    그룹에 포함할 로봇을 선택합니다.

대상 그룹 입력 규칙

항목 규칙 비고
그룹 이름 필수 입력 중복 불가
설명 선택 입력 그룹에 대한 설명
로봇 필수 선택 그룹에 포함할 로봇

문제 해결

문제 원인 해결 방법
캠페인 생성 실패 아티팩트 또는 대상 그룹 미선택 필수 항목을 모두 선택
업데이트 실패 로봇이 오프라인 또는 배터리 부족 로봇 상태 확인 후 재시도
아티팩트 업로드 실패 지원하지 않는 파일 형식 또는 용량 초과 지원 형식 및 용량 확인
