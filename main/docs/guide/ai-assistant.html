AI 어시스턴트 개요

AI 어시스턴트는 화면 우측 하단의 채팅 패널로, 자연어 명령을 통해 로봇과 태스크플로우를 제어할 수 있는 기능입니다. 태스크플로우 실행, 일시정지, 재개, 중지, 삭제, 복사 등 다양한 작업을 채팅으로 수행할 수 있습니다.

사용 방법

AI 어시스턴트를 사용하여 로봇과 태스크플로우를 제어합니다.

AI 어시스턴트 사용 절차

  1. 1

    AI 어시스턴트 패널 열기

    화면 우측 하단의 AI 어시스턴트 아이콘을 클릭합니다.

  2. 2

    명령 입력

    자연어로 원하는 작업을 입력합니다.

  3. 3

    명령 실행

    AI가 명령을 해석하여 작업을 실행합니다.

  4. 4

    결과 확인

    실행 결과를 채팅으로 확인합니다.

지원 명령

AI 어시스턴트에서 사용할 수 있는 주요 명령을 소개합니다.

태스크플로우 제어 명령

명령 설명 예시
실행 태스크플로우를 실행합니다. "순찰 태스크를 실행해줘"
일시정지 실행 중인 태스크플로우를 일시정지합니다. "순찰 태스크를 일시정지해줘"
재개 일시정지된 태스크플로우를 재개합니다. "순찰 태스크를 재개해줘"
중지 실행 중인 태스크플로우를 중지합니다. "순찰 태스크를 중지해줘"
삭제 태스크플로우를 삭제합니다. "순찰 태스크를 삭제해줘"
복사 태스크플로우를 복사합니다. "순찰 태스크를 복사해줘"

기타 명령

명령 설명 예시
도움말 사용 가능한 명령 목록을 표시합니다. "도움말" 또는 "help"
노드 초기화 캔버스의 모든 노드를 초기화합니다. "노드를 초기화해줘"
노드 삭제 선택한 노드를 삭제합니다. "선택한 노드를 삭제해줘"
실행 취소 마지막 작업을 되돌립니다. "실행 취소해줘"
재실행 취소한 작업을 다시 실행합니다. "재실행해줘"

명령 예시

실제 사용할 수 있는 명령 예시를 확인합니다.

"Robot-01에 순찰 태스크를 실행해줘"

Robot-01에 배포된 순찰 태스크를 실행합니다.

"모든 로봇의 태스크를 중지해줘"

모든 로봇에서 실행 중인 태스크플로우를 중지합니다.

"배송 태스크를 복사해서 새로 만들어줘"

배송 태스크를 복사하여 새 태스크플로우를 생성합니다.

문제 해결

문제 원인 해결 방법
명령을 이해하지 못함 지원하지 않는 명령 형식 "도움말"을 입력하여 지원 명령 확인
태스크플로우 실행 실패 로봇이 오프라인 또는 태스크 미배포 로봇 상태 및 배포 상태 확인
명령 실행 지연 네트워크 지연 또는 시스템 부하 잠시 후 다시 시도
