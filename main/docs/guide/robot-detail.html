태스크플로우 실행 절차

  1. 1

    로봇 선택

    대시보드 또는 로봇 목록에서 로봇을 선택합니다.

  2. 2

    태스크플로우 확인

    로봇에 배포된 태스크플로우가 있는지 확인합니다.

  3. 3

    실행 버튼 클릭

    "실행" 버튼을 클릭하여 태스크플로우를 실행합니다.

  4. 4

    상태 확인

    실행 상태와 진행률을 확인합니다.

로그 리플레이

로봇의 과거 이동 경로와 행동을 리플레이하여 분석할 수 있습니다.

로그 리플레이 절차

  1. 1

    로그 리플레이 메뉴 선택

    로봇 상세 페이지에서 "로그 리플레이" 메뉴를 선택합니다.

  2. 2

    기간 선택

    리플레이할 기간을 선택합니다.

  3. 3

    리플레이 실행

    리플레이를 실행하여 로봇의 이동 경로를 확인합니다.

리플레이 컨트롤

컨트롤 설명
재생/일시정지 리플레이를 재생하거나 일시정지합니다.
속도 조절 리플레이 속도를 0.5x, 1x, 2x 등으로 조절합니다.
타임라인 특정 시점으로 이동하여 로봇의 상태를 확인합니다.
