캔버스 에디터 개요

캔버스 에디터는 태스크플로우를 시각적으로 설계하는 도구입니다. 팔레트에서 태스크 노드를 드래그하여 배치하고, 노드를 연결하여 로봇의 작업 흐름을 정의합니다.

에디터 구성

캔버스 에디터는 3개의 주요 패널로 구성됩니다.

팔레트 패널

태스크 노드를 드래그하여 캔버스에 배치합니다. 제어, 동작, 콘텐츠 카테고리로 구분됩니다.

캔버스 영역

노드를 배치하고 연결하는 작업 영역입니다. 확대/축소, 이동, 정렬 기능을 제공합니다.

속성 패널

선택한 노드 또는 연결선의 속성을 설정합니다. 노드 이름, 목적지, 속도 등을 설정합니다.

팔레트 노드 유형

카테고리 노드 유형 설명
제어 시작, 종료, 조건, 반복 태스크 흐름을 제어하는 노드
동작 이동, 회전, 대기, 촬영 로봇의 물리적 동작을 수행하는 노드
콘텐츠 안내, 표시, 음성 로봇이 출력하는 콘텐츠 노드

노드 배치 및 연결

팔레트에서 노드를 드래그하여 캔버스에 배치하고, 노드 간 연결선을 생성합니다.

노드 배치 절차

  1. 1

    팔레트에서 노드 선택

    팔레트 패널에서 원하는 노드를 선택합니다.

  2. 2

    캔버스에 드래그

    노드를 캔버스의 원하는 위치에 드래그하여 배치합니다.

  3. 3

    노드 연결

    노드의 핸들을 드래그하여 다른 노드와 연결합니다.

  4. 4

    속성 설정

    속성 패널에서 노드의 세부 속성을 설정합니다.

노드 속성 설정

노드 유형 주요 속성 설명
이동 목적지, 속도, 회전 이동 목적지와 속도를 설정
안내 메시지, 음성, 표시 안내 메시지와 출력 방식을 설정
조건 조건식, 분기 조건에 따른 분기 흐름을 설정
촬영 카메라, 해상도, 저장 촬영 설정을 구성

저장 및 배포

작성한 태스크플로우를 저장하고 로봇에 배포합니다.

저장 기능

기능 설명 사용 시점
임시 저장 작업 중간 상태를 저장합니다. 작업을 계속 이어가고 싶을 때
최종 저장 태스크플로우를 최종 확정합니다. 작업이 완료되었을 때
실행 취소/재실행 작업을 되돌리거나 다시 실행합니다. 작업 중 실수했을 때

배포 절차

  1. 1

    최종 저장

    태스크플로우를 최종 저장합니다.

  2. 2

    배포 페이지 이동

    배포 페이지에서 태스크플로우를 선택합니다.

  3. 3

    로봇 선택

    배포할 로봇을 선택합니다.

  4. 4

    배포 실행

    배포 버튼을 클릭하여 로봇에 배포합니다.

문제 해결

문제 원인 해결 방법
노드 연결 불가 호환되지 않는 노드 유형 호환되는 노드 유형으로 연결
최종 저장 실패 시작/종료 노드가 없거나 연결이 끊김 시작/종료 노드와 연결 상태 확인
배포 실패 로봇이 오프라인 또는 최종 저장 안 됨 로봇 상태 및 저장 상태 확인
