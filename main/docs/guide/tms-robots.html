TMS 로봇 관리 개요

TMS 로봇 관리 페이지에서는 로봇 목록을 확인하고, 각 로봇에 태스크플로우를 배포하거나 해제할 수 있습니다. 로봇의 태스크플로우 실행 상태를 모니터링하고 제어합니다.

배포 관리

로봇에 태스크플로우를 배포하거나 해제합니다.

태스크플로우 배포 절차

  1. 1

    배포할 로봇 선택

    로봇 목록에서 배포할 로봇을 선택합니다.

  2. 2

    배포 버튼 클릭

    로봇의 "배포" 버튼을 클릭합니다.

  3. 3

    태스크플로우 선택

    배포할 태스크플로우를 선택합니다.

  4. 4

    배포 확인

    배포 확인 모달에서 확인 버튼을 클릭합니다.

배포 입력 규칙

항목 규칙 비고
로봇 온라인 상태여야 함 오프라인 로봇은 배포 불가
태스크플로우 최종 저장된 버전만 선택 가능 임시 저장 버전은 배포 불가

배포 해제

로봇에 배포된 태스크플로우를 해제합니다.

배포 해제 절차

  1. 1

    배포 해제할 로봇 선택

    로봇 목록에서 배포 해제할 로봇을 선택합니다.

  2. 2

    배포 해제 버튼 클릭

    로봇의 "배포 해제" 버튼을 클릭합니다.

  3. 3

    확인

    배포 해제 확인 모달에서 확인 버튼을 클릭합니다.

주의사항

배포 해제 시 실행 중인 태스크플로우가 즉시 중지됩니다. 실행 중인 태스크플로우가 있는 경우 먼저 중지한 후 배포를 해제하세요.

로봇 상세

로봇의 "상세" 버튼을 클릭하여 로봇 상세 페이지로 이동합니다.

로봇 상세에서 확인 가능한 정보

정보 설명
로봇 상태 온라인/오프라인/충전 중 상태
배터리 현재 배터리 잔량
배포된 태스크플로우 현재 배포된 태스크플로우와 버전
실행 상태 태스크플로우 실행/일시정지/중지 상태
태스크플로우 제어 실행, 일시정지, 재개, 중지 버튼

문제 해결

문제 원인 해결 방법
배포 버튼 비활성화 로봇이 오프라인 상태 로봇 연결 상태 확인 후 재시도
배포할 태스크플로우 없음 최종 저장된 태스크플로우가 없음 캔버스 에디터에서 최종 저장
