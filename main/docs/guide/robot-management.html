로봇 관리 개요

로봇 관리 메뉴에서는 로봇의 등록, 그룹 관리, 사이트 관리, 지도 관리, 용어 관리, 사용자 관리 기능을 제공합니다. 로봇을 효율적으로 운영하기 위한 기본 설정을 관리합니다.

로봇 등록

"로봇 등록" 버튼을 클릭하여 새 로봇을 등록합니다.

로봇 등록 절차

  1. 1

    로봇 등록 버튼 클릭

    로봇 관리 탭에서 "로봇 등록" 버튼을 클릭합니다.

  2. 2

    로봇 정보 입력

    로봇 이름, 시리얼 번호, 그룹, 사이트를 입력합니다.

  3. 3

    저장

    저장 버튼을 클릭하여 로봇을 등록합니다.

로봇 등록 입력 규칙

항목 규칙 비고
로봇 이름 필수 입력 중복 불가
시리얼 번호 필수 입력 로봇 하드웨어 시리얼 번호
그룹 선택 입력 그룹 관리에서 생성한 그룹
사이트 선택 입력 사이트 관리에서 생성한 사이트

그룹 관리

로봇을 그룹으로 묶어 효율적으로 관리합니다.

그룹 생성 절차

  1. 1

    그룹 관리 탭 선택

    로봇 관리 메뉴에서 "그룹 관리" 탭을 선택합니다.

  2. 2

    그룹 생성

    그룹 이름과 설명을 입력하고 생성합니다.

  3. 3

    로봇 배정

    그룹에 로봇을 배정합니다.

그룹 관리 입력 규칙

항목 규칙 비고
그룹 이름 필수 입력 중복 불가
설명 선택 입력 그룹에 대한 설명

사이트 관리

로봇이 운영되는 사이트(지점)를 관리합니다.

사이트 생성 절차

  1. 1

    사이트 관리 탭 선택

    로봇 관리 메뉴에서 "사이트 관리" 탭을 선택합니다.

  2. 2

    사이트 생성

    사이트 이름, 주소, 좌표를 입력하고 생성합니다.

  3. 3

    지도 연결

    사이트에 지도를 연결합니다.

사이트 관리 입력 규칙

항목 규칙 비고
사이트 이름 필수 입력 중복 불가
주소 선택 입력 사이트 물리적 주소
좌표 선택 입력 위도/경도

지도 관리

로봇이 이동하는 공간의 지도를 업로드하고 관리합니다.

지도 업로드 절차

  1. 1

    지도 관리 탭 선택

    로봇 관리 메뉴에서 "지도 관리" 탭을 선택합니다.

  2. 2

    지도 파일 업로드

    지도 이미지 파일을 업로드합니다.

  3. 3

    지도 정보 입력

    지도 이름, 사이트, 좌표 정보를 입력합니다.

지도 관리 입력 규칙

항목 규칙 비고
지도 파일 필수 (이미지 파일) PNG, JPG, SVG 등
지도 이름 필수 입력 중복 불가
사이트 필수 선택 지도가 사용될 사이트

문제 해결

문제 원인 해결 방법
로봇 등록 시 중복 오류 이미 등록된 로봇 이름 또는 시리얼 번호 다른 이름/시리얼 번호로 등록
지도 업로드 실패 지원하지 않는 파일 형식 또는 용량 초과 지원 형식(PNG, JPG, SVG) 및 용량 확인
그룹 삭제 불가 그룹에 로봇이 배정되어 있음 그룹에서 로봇을 먼저 제거 후 삭제
