시작하기 개요

OPCON 서비스를 사용하기 위해서는 먼저 계정이 필요합니다. 계정 생성은 두 가지 방법이 있습니다:

직접 회원가입

이메일 인증을 통해 직접 계정을 생성합니다.

초대 수락

관리자가 보낸 초대 이메일의 링크를 통해 계정을 생성합니다.

1. 로그인

로그인 화면에서 이메일과 비밀번호를 입력하여 서비스에 접속합니다.

2. 회원가입

이메일 인증을 통해 계정을 생성합니다. 총 2단계로 진행됩니다.

회원가입 절차

  1. 1

    이메일 입력 및 인증 코드 요청

    회원가입 탭에서 이메일을 입력하고 "인증 코드 전송" 버튼을 클릭합니다.

  2. 2

    인증 코드 확인 및 정보 입력

    이메일로 받은 인증 코드(8자리 숫자)를 입력하고, 닉네임과 인가 코드를 입력합니다.

  3. 3

    가입 신청 완료

    가입 신청이 완료되면 이메일로 비밀번호 설정 링크가 발송됩니다.

  4. 4

    비밀번호 설정

    이메일의 링크를 통해 이메일, 새 비밀번호, 비밀번호 확인을 입력하여 계정 생성을 완료합니다.

회원가입 입력 규칙

항목 규칙 비고
이메일 이메일 형식 (필수) 이미 사용 중인 이메일은 가입 불가
인증 코드 8자리 숫자 (필수) 이메일로 수신
닉네임 필수 입력 사용자 표시 이름
인가 코드 필수 입력 관리자에게 발급받은 코드

회원가입 오류 및 해결 방법

오류 메시지 원인 해결 방법
이미 사용 중인 이메일입니다. 이메일 중복 다른 이메일로 가입
인증 코드가 올바르지 않습니다. 인증 코드 불일치 이메일의 인증 코드를 다시 확인
인증 코드가 잠겼습니다. 인증 코드 반복 오류 잠시 후 다시 시도
인가 코드가 올바르지 않습니다. 인가 코드 불일치 관리자에게 인가 코드 재발급 요청

3. 비밀번호 재설정

비밀번호를 잊어버린 경우 이메일을 통해 재설정할 수 있습니다.

비밀번호 재설정 절차

  1. 1

    이메일 입력

    로그인 화면의 "비밀번호 재설정" 탭에서 이메일을 입력합니다.

  2. 2

    초기화 링크 수신

    입력한 이메일로 비밀번호 설정 링크가 발송됩니다.

  3. 3

    새 비밀번호 설정

    링크를 통해 이메일, 새 비밀번호, 비밀번호 확인을 입력합니다.

비밀번호 설정 입력 규칙

항목 규칙 비고
이메일 이메일 형식 (필수) 가입 시 사용한 이메일
새 비밀번호 필수 입력 -
비밀번호 확인 새 비밀번호와 일치해야 함 불일치 시 오류 표시

4. 초대 수락

관리자가 보낸 초대 이메일의 링크를 통해 계정을 생성합니다.

초대 수락 절차

  1. 1

    초대 이메일 수신

    관리자가 보낸 초대 이메일의 링크를 클릭합니다.

  2. 2

    계정 정보 입력

    이메일, 닉네임, 새 비밀번호, 비밀번호 확인을 입력합니다.

  3. 3

    가입 완료

    가입이 완료되면 로그인 화면으로 이동합니다.

초대 수락 입력 규칙

항목 규칙 비고
이메일 이메일 형식 (필수) 초대받은 이메일
닉네임 필수 입력 사용자 표시 이름
새 비밀번호 필수 입력 -
비밀번호 확인 새 비밀번호와 일치해야 함 불일치 시 오류 표시

5. 언어 설정

로그인 화면 우측 상단에서 언어를 선택할 수 있습니다.
