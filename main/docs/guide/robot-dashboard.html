로봇 대시보드 개요

로봇 대시보드는 등록된 모든 로봇의 상태를 한눈에 확인할 수 있는 화면입니다. 로봇의 배터리, 연결 상태, 알람, 학습 상태 등을 실시간으로 모니터링할 수 있습니다.

주요 기능

배터리 모니터링

모든 로봇의 배터리 잔량을 실시간으로 확인하고, 충전이 필요한 로봇을 식별합니다.

연결 상태 확인

로봇의 온라인/오프라인 상태를 확인하고, 연결이 끊긴 로봇을 신속히 파악합니다.

알람 관리

로봇에서 발생한 알람을 확인하고, 심각도에 따라 우선순위를 정해 대응합니다.

학습 상태 확인

로봇의 학습 진행 상태를 확인하고, 학습이 필요한 로봇을 식별합니다.

로봇 상태 가이드

상태 표시 색상 설명 조치
온라인 초록 로봇이 정상적으로 연결됨 -
충전 중 노랑 로봇이 충전 스테이션에서 충전 중 충전 완료 후 작업 재개
오프라인 빨강 로봇과 연결이 끊김 로봇 전원 및 네트워크 확인
작업 중 파랑 로봇이 태스크플로우를 실행 중 -

문제 해결

문제 원인 해결 방법
로봇이 오프라인으로 표시됨 로봇 전원 꺼짐 또는 네트워크 연결 끊김 로봇 전원을 켜고 네트워크 연결을 확인
