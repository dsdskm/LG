콘텐츠 관리 개요

CMS(Content Management System)는 로봇이 사용하는 콘텐츠(안내문, 광고, 정보 등)를 관리하는 기능입니다. 콘텐츠 생성, 카테고리 관리, 콘텐츠 타입 설정, 임베딩, TTS(음성 변환) 기능을 제공합니다.

콘텐츠 생성

"콘텐츠 생성" 버튼을 클릭하여 새 콘텐츠를 생성합니다.

콘텐츠 생성 절차

  1. 1

    콘텐츠 생성 버튼 클릭

    콘텐츠 탭에서 "콘텐츠 생성" 버튼을 클릭합니다.

  2. 2

    콘텐츠 정보 입력

    제목, 카테고리, 콘텐츠 타입, 내용을 입력합니다.

  3. 3

    저장 및 게시

    임시 저장 또는 게시를 선택합니다.

콘텐츠 생성 입력 규칙

항목 규칙 비고
제목 필수 입력 콘텐츠 제목
카테고리 필수 선택 카테고리 관리에서 생성한 카테고리
콘텐츠 타입 필수 선택 텍스트, 이미지, 비디오 등
내용 타입에 따라 필수 텍스트/파일 업로드

카테고리 관리

콘텐츠를 분류하기 위한 카테고리를 관리합니다.

카테고리 생성 절차

  1. 1

    카테고리 탭 선택

    CMS 메뉴에서 "카테고리" 탭을 선택합니다.

  2. 2

    카테고리 생성

    카테고리 이름과 설명을 입력하고 생성합니다.

  3. 3

    콘텐츠 연결

    콘텐츠 생성 시 카테고리를 선택합니다.

카테고리 입력 규칙

항목 규칙 비고
카테고리 이름 필수 입력 중복 불가
설명 선택 입력 카테고리에 대한 설명

콘텐츠 타입 관리

콘텐츠의 유형(텍스트, 이미지, 비디오 등)을 정의합니다.

콘텐츠 타입

타입 설명 사용 예시
텍스트 텍스트 기반 콘텐츠 안내문, 공지사항
이미지 이미지 파일 기반 콘텐츠 배너, 포스터
비디오 비디오 파일 기반 콘텐츠 홍보 영상
오디오 오디오 파일 기반 콘텐츠 음성 안내

임베딩 및 TTS

콘텐츠의 의미를 벡터화하는 임베딩과 텍스트를 음성으로 변환하는 TTS 기능을 제공합니다.

임베딩

콘텐츠를 벡터로 변환하여 AI 검색 및 추천에 활용합니다.

임베딩 생성 절차

  1. 임베딩 탭 선택
  2. 임베딩할 콘텐츠 선택
  3. 임베딩 생성 실행

TTS 도구

텍스트를 음성으로 변환하여 로봇의 음성 안내에 활용합니다.

TTS 생성 절차

  1. TTS 도구 탭 선택
  2. 텍스트 입력
  3. 음성 설정 (언어, 목소리)
  4. TTS 생성 실행

TTS 입력 규칙

항목 규칙 비고
텍스트 필수 입력 음성으로 변환할 텍스트
언어 필수 선택 한국어, 영어, 일본어
목소리 필수 선택 남성/여성 목소리

문제 해결

문제 원인 해결 방법
콘텐츠 생성 실패 필수 항목 미입력 제목, 카테고리, 타입을 모두 입력
임베딩 생성 실패 콘텐츠가 게시되지 않음 콘텐츠를 게시한 후 임베딩 생성
TTS 생성 실패 텍스트가 너무 길거나 언어 미선택 텍스트 길이 및 언어 설정 확인
