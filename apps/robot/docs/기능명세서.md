## 1. 앱 개요

Robot App은 **로봇 플릿(운영 중인 다수의 서비스 로봇)을 원격으로 모니터링·제어·관리**하는 통합 운영관제 시스템의 하위 애플리케이션입니다. 크게 아래 4가지 축의 기능을 제공합니다.

```
[모니터링]  대시보드 / TV 대시보드 / 알람 / 데이터 수집 현황
[운영/제어]  로봇 목록·상세 제어 / 위치 이동 / Task 실행
[구성 관리]  지도 관리 / 그룹·사이트 관리 / 사용자·약관 관리
[AI 분석]    이벤트 자동 분류·리포트 / 로그·로봇팔 리플레이 분석
```

조직 구조는 **Group(그룹사) → Site(사업장) → Building(건물) → Floor(층) → Area(구역)** 계층으로 관리되며, 로봇(Device)은 특정 Site에 배정(provision)되어 운영됩니다.

## 2. 사용자 역할 및 메뉴 접근 권한

| 역할 | userLevel | 설명 |
| --- | --- | --- |
| SITE_MANAGER | 0 | 사업장 단위 운영 담당자 |
| GROUP_MANAGER | 1 | 그룹사 단위 운영 담당자 |
| SYSTEM_MANAGER | 2 | 시스템 운영/사용자 관리 담당자 |
| SYSTEM_ADMIN | 3 | 시스템 전체 관리자 |
| TERM_MANAGER | 4 | 약관/정책 콘텐츠 관리 전용 역할 (일반 운영 메뉴 접근 불가) |

| 메뉴 | 경로 | 접근 가능 역할 |
| --- | --- | --- |
| 대시보드 | `/robot/dashboard` | SITE_MANAGER ~ SYSTEM_ADMIN (전체) |
| 로봇 관리 | `/robot/management`, `/detail` | SITE_MANAGER ~ SYSTEM_ADMIN (전체) |
| 지도 관리 | `/robot/maps`, `/detail`, `/history` | SITE_MANAGER ~ SYSTEM_ADMIN (전체) |
| AI 로그 관리 | `/robot/ailog/:tab` | GROUP_MANAGER ~ SYSTEM_ADMIN |
| 그룹 관리 | `/robot/groups`, `/sitedetail` | GROUP_MANAGER ~ SYSTEM_ADMIN |
| 사용자 관리 | `/robot/users` | SYSTEM_MANAGER, SYSTEM_ADMIN |
| 약관 관리 (설정) | `/robot/terms` | SYSTEM_ADMIN, TERM_MANAGER |

> TERM_MANAGER 로그인 시 대시보드 등 일반 메뉴 진입이 자동으로 `/robot/terms`로 리다이렉트됩니다 — 이 역할은 약관 관리 외 기능을 사용하지 않는 전용 계정입니다.
> `/robot/logreplay`, `/robot/replaycontrols`, `/robot/tv`, `/robot/apitest`, `/robot/sitedetail`은 좌측 GNB 메뉴에는 노출되지 않고, 각 화면 내 버튼/링크를 통해서만 진입하는 **보조 화면**입니다.

## 3. 대시보드

**경로**: `/robot/dashboard`

로봇 플릿의 현재 상태를 한눈에 파악하는 메인 화면입니다.

- **조직 선택**: 그룹/사이트를 선택하면 화면이 "지역 지도" 모드(전체 사이트 분포)에서 "사이트 지도" 모드(선택 사이트의 층/구역 평면도)로 전환됩니다.
- **로봇 상태 카드**: 가동중/대기/충전중/오류/오프라인 5개 상태별 로봇 수를 카드로 표시하며, 카드 클릭 시 해당 상태로 필터링된 로봇 관리 목록으로 이동합니다.
- **지역 지도(카카오맵)**: 사이트를 아직 선택하지 않았을 때 표시되며, 사이트별 마커에 마우스 오버 시 운영/대기/충전/오류/오프라인/전체 로봇 수 툴팁을 보여줍니다. 확대 레벨에 따라 개별 마커 ↔ 클러스터 마커로 자동 전환됩니다.
- **사이트 지도(2D/3D)**: 사이트를 선택하면 건물/층/구역을 단계적으로 선택할 수 있고, 선택된 구역의 평면도 위에 로봇 위치·방향이 실시간으로 표시됩니다. 2D(평면)와 3D(입체 렌더링) 보기를 토글할 수 있으며, "Live" 버튼으로 1초 간격 실시간 갱신을 켜고 끌 수 있습니다(브라우저 탭이 비활성화되면 자동 일시정지).
- **알람 테이블**: 현재 활성화된(해소되지 않은) 로봇 오류를 사이트/로봇/오류 내용/발생 시각으로 표시하는 접이식 테이블입니다.
- **데이터 수집 현황**: 학습 데이터 수집 목표 대비 실적(누적/월/일 단위), 데이터 품질 추이, 저장공간 사용량을 차트로 보여주는 접이식 섹션입니다. *(※ 현재는 목(mock) 데이터로 표시되며 실 API 연동은 예정 상태입니다.)*
- **AI 이벤트 요약**: 화면 상단(모든 페이지 공통)에 오늘 발생한 AI 이벤트 건수(전체/조치완료/분석완료/심각도별)를 요약해서 보여줍니다.
- **TV 보기**: 현재 선택한 그룹/사이트를 유지한 채 [TV 대시보드](#4-tv-대시보드)를 새 창으로 엽니다.

## 4. TV 대시보드

**경로**: `/robot/tv` (대시보드의 "TV 보기" 버튼으로만 진입)

사무실/현장에 상시 게시하는 **키오스크(전시용) 화면**입니다. 마우스 조작이 필요 없는 자동 순환 뷰로, 대시보드와 달리:

- 1920×1080 고정 캔버스를 화면 크기에 맞춰 자동 스케일링합니다.
- URL 파라미터(`group`, `site`)로만 대상이 결정되며 화면 내 조직 선택 UI가 없습니다.
- 사업장의 여러 구역을 60초 주기로 3개씩 자동으로 순환 표시합니다.
- Solid/Gradient 2가지 색상 테마를 화면 내 버튼으로 전환할 수 있습니다.
- 알람 테이블과 조직 선택 UI를 제외하고, 로봇 상태 카드/지도/데이터 수집 현황을 그대로 재사용합니다.

## 5. 로봇 관리 (목록/상세)

### 5.1 로봇 목록 (`/robot/management`)

- 그룹/사이트, 등록상태(등록/사용중/삭제), 운영상태(대기/충전/가동/오프라인/전원꺼짐/오류), 이름·시리얼·MAC 검색어로 로봇 목록을 필터링합니다.
- 대시보드 상태 카드에서 진입 시 해당 운영상태로 사전 필터링된 상태로 열립니다.
- 로봇명을 클릭하면 [로봇 상세](#52-로봇-상세-robotmanagementdetail)로 이동합니다.

### 5.2 로봇 상세 (`/robot/management/detail`)

3개 탭으로 구성된 개별 로봇 제어/조회 화면입니다.

- **기본정보(AssetInfo)**: 로봇 식별정보, 실시간(1초 폴링) 상태 갱신 토글, 현재 위치가 표시된 지도, 최근 오류 이력, 부품 상태 패널, 이름 변경/삭제 등을 제공합니다. 아래 **로봇 제어판**을 포함합니다.
  - **기본 제어**: 이동(위치/POI 선택), 충전 복귀, 리슨, 비상정지(현재 비활성), 종료, 재부팅, GKR
  - **Task 제어**: Taskflow 선택 후 시작/정지/일시정지/재개
  - **특수 모드**: 자유주행(free-run), 제로게인 On/Off
  - **회전 제어**: 좌/우 회전(각도 프리셋)
  - **모션 라이브러리**: 인사, RPS 등 사전 정의된 17종 모션 실행
  - 채널이 특수 단말(RF)인 경우 REST 대신 단말 내 웹뷰 브릿지를 통해 명령이 전달됩니다.
- **웹 콘솔(WebConsole)**: 상태/센서/마이컴/진단/3D뷰/맵설정/POI 등 로봇별 내장 웹 UI를 카드 형태로 배치하는 대시보드로, 사용자가 표시할 카드를 직접 구성(저장은 브라우저별 로컬 저장)할 수 있습니다. 실시간 카드(예: 3D뷰)는 웹소켓으로 스트리밍됩니다.
- **이력(HistoryList)**: 해당 로봇에 전송된 제어 명령 이력을 요청자와 함께 시간순으로 조회합니다.

## 6. 지도 관리

**경로**: `/robot/maps`, `/robot/maps/detail`, `/robot/maps/history`

로봇 주행/서비스에 사용되는 **주행맵(NAVI), POI(관심지점), SVG(도면 오버레이)** 3종 파일을 사업장 구역별(또는 로봇 개별)로 관리합니다.

- **목록**: 그룹/사이트 → 건물/층/구역 순으로 좁혀가며, 구역별 맵 슬롯과 로봇별 개별 맵 슬롯을 함께 보여줍니다. 맵이 없는 슬롯은 클릭 시 업로드 화면으로 이동합니다.
- **상세**: 맵 종류/위치/그룹·사이트 정보를 보여주고, 최신 버전 파일을 다운로드하거나 새 버전을 업로드(사전 서명 URL 방식)할 수 있습니다. 주행맵은 2D 평면도로 미리보기됩니다.
- **버전 이력**: 맵의 모든 업로드 버전을 주행맵 버전 기준으로 그룹핑해서 보여주고, 임의의 두 버전을 **나란히 비교**할 수 있으며, 과거 버전을 **롤백**(재업로드하여 최신으로 승격)할 수 있습니다.

## 7. 그룹 관리 / 사이트 상세

**경로**: `/robot/groups`, `/robot/groups/sitedetail`

- **그룹 관리 목록**: 그룹을 행 확장 시 하위 사이트 목록이 펼쳐지며, 그룹명 생성/수정, 사이트 추가를 할 수 있습니다.
- **사이트 편집**: 사이트명/주소(우편번호 검색+카카오 지오코딩으로 위경도 자동 입력)를 관리하고, 하위 **건물 → 층 → 구역**을 추가/이름변경/삭제할 수 있습니다. 층은 지상/지하 여부와 층 순서를 지정하면 이름이 자동 생성(`1F`, `B2` 등)되고, 구역은 A, B, C… 순으로 자동 명명됩니다. 로봇이 배정된 위치는 삭제가 제한됩니다.
- **사이트 상세**: 특정 사이트에 속한 로봇을 3개 탭으로 관리합니다.
  - **현재 사이트**: 이 사이트에 배정된 로봇 목록
  - **미배정**: 아직 어떤 사이트에도 배정되지 않은(기본 풀에 있는) 로봇 — 이 사이트로 배정 가능
  - **다른 사이트**: 이미 타 사이트에 배정된 로봇 — 이 사이트로 재배정(이동) 가능

## 8. AI 로그 관리

**경로**: `/robot/ailog/:tab`

로봇이 발생시키는 로그를 AI가 자동으로 분류·분석하여 이상 상황을 탐지하고, 조치·리포트까지 이어지는 **AI 이벤트 운영 콘솔**입니다.

```
로봇 로그 수신 → AI 분류(기능 판별) → AI 분석(원인·심각도·해결책) → 조치(Action) 추천/실행 → 리포트 발송
```

| 탭 | 기능 |
| --- | --- |
| **이벤트** | 발생한 이벤트를 기간/심각도/기능/상태/키워드로 검색·조회. 요약 카드(전체/조치완료/분석완료/분석실패/심각도별 건수)를 상단에 표시. 행 클릭 시 상세 패널에서 원본 로그, 분석 결과(원인/해결책), 추천 조치를 확인·실행하고 분석 내용을 직접 수정할 수 있습니다. |
| **통계** | 기간별 로그를 집계하여 로봇별/기능별 이슈 Top 10, 추천 조치 빈도, 시간대별(3시간 단위) 이슈 발생량을 차트로 제공합니다. |
| **기능 관리** | 이벤트를 분류하는 "기능(예: 주행, 서비스)" 단위를 등록·관리합니다. 각 기능은 분석용 프롬프트, 분류 태그, 담당자를 가지며, 설정 완료 여부로 필터링할 수 있습니다. |
| **액션 관리** | 이벤트에 대해 실행 가능한 조치(재부팅 요청 등)를 등록·관리합니다. 특정 기능에만 적용되도록 제한할 수 있습니다. |
| **프롬프트 관리** | AI 분류·분석에 사용되는 LLM 프롬프트를 관리합니다. 1단계(로그→기능 분류, 고정)와 2단계(기능별 세부 분석, 공통+기능별 프롬프트 조합) 구조이며, LLM 제공자 선택 및 미리보기를 제공합니다. |
| **담당자 관리** | 기능별 담당자(이름/이메일/팀)를 등록·관리합니다. |
| **리포트** | 이벤트 발생 시 발송되는 이메일 형태 리포트 템플릿(제목/본문 HTML)을 토큰 치환 방식으로 편집하고 미리볼 수 있습니다. |
| **AI 챗봇 설정** *(GNB 미노출, AI 어시스턴트 패널의 설정 아이콘으로 진입)* | 통합 운영관제 전체(robot/ota/cms/tms 공통)에서 쓰이는 AI 챗봇의 공통 프롬프트, 화면별 프롬프트·가이드·RAG 문서·호출 가능 API(Screen Tool), 이벤트 조회용 규칙(패턴 매칭), Taskflow 대화용 규칙, 대화 이력 조회를 관리하는 별도의 대형 설정 화면입니다. |

## 9. 사용자 관리

**경로**: `/robot/users`

사용자 초대부터 승인, 목록 관리까지 전체 라이프사이클을 관리합니다.

1. **초대**: 관리자가 이메일/역할/그룹·사이트/초대 이유를 입력해 초대장을 발송합니다.
2. **가입 승인**: 초대받은 사용자가 가입 신청을 하면 "권한 승인" 탭에 대기 목록으로 노출되며, 관리자가 승인/반려(사유 입력) 처리합니다.
3. **목록 관리**: 승인된 사용자의 역할/그룹/사이트를 수정하거나 계정을 삭제합니다. *(계정 정지 기능은 UI만 존재하며 현재 비활성화되어 있습니다.)*

권한 규칙: 사용자는 자신보다 높은 등급의 계정을 볼 수 없고, 초대/역할 변경 시에도 자신보다 높은 등급을 부여할 수 없습니다. TERM_MANAGER 역할은 SYSTEM_ADMIN만 부여할 수 있습니다.

## 10. 약관 관리

**경로**: `/robot/terms` (좌측 GNB "설정" 하위)

서비스 이용약관/개인정보처리방침 등 정책 문서를 버전 관리합니다.

- 약관 그룹(서비스 정책/개인정보/마케팅수신/제3자제공/위치서비스), 버전(주.부), 지원 언어(한/영/일 등), 필수 동의 여부, 활성 여부를 관리합니다.
- **등록**: 마크다운 본문을 업로드(사전 서명 URL) → 메타데이터 저장 순서로 진행되며, 등록 후 본문/버전은 수정할 수 없습니다.
- **수정**: 필수 동의 여부/활성 여부만 변경 가능합니다.
- **보기**: 언어별 약관 본문을 CDN에서 불러와 화면 내에서 확인합니다.

## 11. 로그 리플레이 / 로봇팔 분석 리플레이

GNB에는 노출되지 않고, 로봇 목록/상세 화면의 "로그 리플레이" 버튼 등을 통해 팝업으로 진입합니다.

### 11.1 로그 리플레이 (`/robot/logreplay`)

로봇의 **주행/내비게이션 로그를 재생하며 디버깅**하는 도구입니다.

- 로봇·날짜 기준으로 로그 파일(.mcap) 목록을 조회하고 하나를 선택해 재생합니다.
- 2D 주행 지도에 점유격자맵, 주행 경로, 계획 경로, 로컬 코스트맵, 목표 지점/방향, 라이다 스캔을 겹쳐서 표시하며 각 항목을 켜고 끌 수 있습니다. 필요 시 3D 보기로도 전환 가능합니다.
- 속도/좌표 등 센서 값 추이를 그래프로 표시합니다.
- 로그 텍스트를 키워드/레벨로 빠르게 검색할 수 있습니다.
- 재생바로 구간 이동/프레임 이동/재생 속도 조절이 가능하며, 외부 뷰어(Lichtblick)로 열거나 원본 파일을 다운로드할 수 있습니다.

### 11.2 로봇팔 분석 리플레이 (`/robot/replaycontrols`)

**로봇팔(매니퓰레이터)의 동작 품질을 분석**하는 전용 도구입니다.

- 로그에 포함된 로봇 3D 모델(URDF)을 불러와, 관절 상태(`/joint_states`) 값에 맞춰 3D 로봇 모델이 실제 동작과 동일하게 움직이는 것을 재생합니다.
- **개요/팔 분석/엔드이펙터/성능/시스템 상태** 5개 탭으로 좌/우 팔, 손끝(그리퍼), 배터리, 진단 정보를 분석합니다.
  - 관절별 위치/속도/토크 그래프와 동작 안정성(부드러움) 지표
  - 손가락 굽힘 정도, 파지(grasp)/오픈 상태 판정, 좌우 비대칭도
  - 목표 대비 실제 추종 성능, 성공률, 문제 진단 요약
- 경고/오류 판정 기준값(속도·토크·비대칭도 등)을 사용자가 직접 조정할 수 있으며 브라우저에 저장되어 다음 사용 시에도 유지됩니다. *(※ 기준값은 정식 스펙이 아닌 추정치 기준으로 명시되어 있습니다.)*
